# Aether Trail — ต้นแบบโมเดล 3 มิติ v0.1

ชุดนี้เป็นโมเดล 3 มิติจริงแบบ procedural blockout สำหรับทดสอบระบบ ไม่ใช่งานปั้นละเอียดเหมือนภาพเรนเดอร์ก่อนหน้า และยังไม่ได้ติดตั้งในเกมเดิม

## เริ่มดูได้ทันที

1. แตกไฟล์ ZIP
2. เปิด `Aether_Trail_3D_Viewer.html` ในเบราว์เซอร์ที่รองรับ WebGL
3. เลือกชาย/หญิง ชุด และท่าทาง ลากเพื่อหมุน ใช้ล้อเมาส์ซูม
4. เลือกดาวน์โหลด GLB ที่ต้องการ หรือใช้ไฟล์ในโฟลเดอร์ `models`

หน้าดูตัวอย่างทำงานออฟไลน์ โมเดลทั้งหมดฝังอยู่ใน HTML ไม่มี CDN ไม่มีการส่งข้อมูลออก

## สิ่งที่มี

- ไฟล์ GLB 8 โมเดล: ชาย 4 ชุด หญิง 4 ชุด
- ชุด traveler (นักผจญภัย), sovereign (ผู้ครองเมือง), commander (แม่ทัพ), celestial (ดาราจักร)
- แต่ละโมเดลมีโครงกระดูก 18 ข้อต่อ ใช้ผิววัสดุสีพื้น และ skin weights จริง
- คลิป Idle, Walk, Run, Attack, Cast, Hit, Victory, Defeat รวม 8 คลิปต่อไฟล์
- GIF แสดงการเคลื่อนไหวที่เรนเดอร์จากโครงกระดูกเดียวกับไฟล์โมเดล
- ภาพรวมคอสตูมจากโมเดลจริง และ Python source สำหรับสร้างใหม่

## ขอบเขตของต้นแบบ

- รูปทรงหน้าตา ผม และเสื้อผ้ายังเป็นชิ้นเรขาคณิตแบบเรียบ ไม่มี UV หรือ texture ละเอียด
- น้ำหนักเป็นแบบแข็ง 1 ข้อต่อต่อชิ้นส่วน ข้อศอก/หัวเข่าจึงเห็นรอยต่อ ควรเปลี่ยนเป็นผิวต่อเนื่องและ blend weights ในขั้นงานจริง
- ผ้าคลุมมีข้อต่อแยก 1 จุด ไม่มี cloth simulation; เปียผูกกับศีรษะ ไม่มี hair physics
- ไม่มี facial rig, การกะพริบตา, lip sync, finger rig, IK, foot lock หรือ root motion
- ดาบเป็นอุปกรณ์ที่ถืออยู่ มีข้อต่อ Sword; ตัวอย่างไม่มีเอฟเฟกต์สกิลหรือระบบต่อสู้
- คอสตูมเป็นโมเดลแยกทั้งตัว สลับทั้งไฟล์ได้ ยังไม่ใช่ระบบผสมเสื้อ/กางเกง/รองเท้าเป็นชิ้นอิสระ
- ไม่มี FBX หรือไฟล์ .blend; หากต้องการ ให้ import GLB ในเครื่องมือ 3 มิติแล้วบันทึกหรือ export ต่อ

## ส่งต่อผู้พัฒนา

แกน +Y ขึ้น, +Z ด้านหน้า, หน่วยเมตร, ใช้ชื่อข้อต่อเหมือนกันทุกชุด เลือกนำเข้า GLB พร้อม skin และ animations ใน engine ของโครงการ จากนั้นใช้ชื่อคลิปตามตารางเชื่อมกับสถานะตัวละคร ข้อมูลเจ้าของไอดีควรเก็บ sex, costume และชื่อผู้เล่นแยกจาก roster ฮีโร่กาชา

ขั้นงานผลิตที่เหลือ: ปั้นตามภาพอ้างอิงเดิม, retopology, UV/texture, ปรับ skin weights, ตรวจการชนกันของชุด, ทำท่าเดินที่เท้าไม่ไถล, เพิ่ม facial rig ตามต้องการ และตรวจประสิทธิภาพบนมือถือจริง

## สร้างไฟล์ใหม่

ต้องมี Python 3, numpy, Pillow และฟอนต์ DejaVu Sans (ปรับค่า FONT ใน source ให้ตรงกับระบบ)

```bash
python source/build_models.py
python source/package_and_validate.py
```

`validation_report.json` เป็นผลตรวจโครงสร้าง GLB และข้อมูลโมเดลด้วยสคริปต์ของชุดนี้ ไม่ใช่ใบรับรองจาก Khronos และยังไม่ผ่านการทดสอบใน Unity/Godot/Blender ของผู้ใช้

หน้าดูตัวอย่างผ่านการตรวจตรรกะ JavaScript และสลับโมเดล/ชุด/คลิป 64 ชุดด้วย DOM/WebGL จำลอง ยังไม่ได้ทดสอบการแสดงผล GPU ในเบราว์เซอร์จริง เนื่องจากเครื่องสร้างไฟล์ไม่มี browser binary ติดตั้ง หากเบราว์เซอร์ของผู้ใช้แสดงผลไม่ได้ ยังสามารถเปิดไฟล์ GLB ในเครื่องมือ 3 มิติและดู GIF ตัวอย่างได้
